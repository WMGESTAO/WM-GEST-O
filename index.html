Backup e segurança

Esta versão guarda os dados neste navegador e neste aparelho. Ela não envia seus dados para um servidor, mas também não sincroniza automaticamente entre celular e computador. Exporte backups regularmente e guarde-os em local seguro.

A restauração substitui os dados atuais. A exclusão é permanente neste aparelho se não houver backup.

Sobre esta versão

WM Gestão · versão 1.0.0 · armazenamento local no navegador · recibos JPG gerados no próprio aparelho.

Para instalar como aplicativo, publique estes arquivos em um site HTTPS estático. Consulte o arquivo LEIA-ME incluído no pacote.
